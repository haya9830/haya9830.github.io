04 / WORKS

制作物

MVP

Fuel Apply

農作業用機械の稼働時間・給油量を、スマートフォンから記録するアプリ

目的
農業用燃料の免税申請に必要な記録の入力を支援すること。
つくったもの
機械ごとの稼働時間と給油量をスマートフォンで入力し、Microsoft Graph経由でOneDrive上のExcelに記録するMVP。機械と農業の経験がそのまま活きるテーマとして取り組んでいます。
現状
MVP（最小限の機能を備えた試作段階）
技術
TypeScript / React Native / Expo / Microsoft Graph
