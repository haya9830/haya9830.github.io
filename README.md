# haya9830 Portfolio

機械・農業の経験と、Web・モバイルアプリの開発を紹介する個人ポートフォリオです。

- 公開ページ: https://haya9830.github.io/
- GitHubプロフィール: https://github.com/haya9830
- 入口: `index.html`

ClaudeのDesign Artifactで制作し、単独HTMLとして書き出しています。ビルドやサーバー側の処理は不要です。フォントはGoogle Fontsを使い、読み込めない場合はシステムフォントで表示します。

更新するときは、元のClaude Artifactを編集してHTMLを書き出し、このリポジトリの`index.html`へ反映します。`main`のルートをGitHub Pagesで公開しています。
