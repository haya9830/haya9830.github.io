# haya9830 Portfolio

機械・農業の経験と、ソフトウェア開発を紹介する個人ポートフォリオです。

- 公開ページ: https://haya9830.github.io/haya9830/
- トップURL: https://haya9830.github.io/ （ポートフォリオへ転送）
- 本文: `haya9830/index.html`
- スタイル: `haya9830/styles.css`
- 動作: `haya9830/script.js`

HTML・CSS・JavaScriptの静的サイトです。ビルドや外部JavaScriptライブラリは不要です。
`main`ブランチのルートをGitHub Pagesで公開しています。

## 更新

本文・制作物・技術スタック・経歴は `haya9830/index.html` を編集します。
技術アイコンのライセンスは `haya9830/assets/skills/NOTICE.txt` にあります。
